**关键设计原则（后续改动必须遵守）**：
1. 层次靠「1px 描边 + 底色阶差 + 留白」，**禁止外发光**。卡片描边 `#2E3D4E` 刻意只有 1.52:1，靠四级底色 ΔL* 3.4/2.9/4.8 承担 80% 层次。
2. 卡高公式 `卡高 = 内容 + 96`（表格卡 88 / 概览卡 108），标题块固定 44px。改卡高必须回文档重算整列。
3. 字号地板 12px，且 12px 只许承载口径/单位/时间；判断性文本必须 ≥14px。
4. 三栏各自独立闭合（762 / 786 / 924），**高度不可跨栏转移**——某栏释放的高度只能被同栏卡片吸收。
5. 空卡预算 ≤140px；同栏 ≥3 张空卡合并为「待接入模块 (N)」聚合卡；「未接入」徽标用灰 `#5F6E80`，**禁用语义色**（未接入不是异常）。
6. 表格 n≤14 取消分页；7 张表全部 ≤14，全站分页控件应为 0。
7. 「0 件/0 例/已固化」是有效结论，四要素必须齐（数值+单位+徽标+口径），不许当空数据。

**验收判据**：E3.1 每张卡 `内容占位 / (卡高−96) ≥ 0.92`；21 栏高度精确；表格横向溢出 0；页面横向滚动 0。

## 23:20 重大方向修正：新增 cockpit 主题

**用户看过实物后反馈「不够炫酷，希望保留原有的驾驶舱感觉」，否决了纯「深沉政务专业风」。**

**处理原则（重要，后续沿用）——分层用光**，而不是简单恢复外发光：
- 氛围层（背景）：可以有光。径向光晕、24px 网格、暗角
- 结构层（卡片边框/标题/导航）：可以有光。切角、描边辉光、顶部高光线
- 内容层（文字/数字/表格）：**绝对禁止发光与 text-shadow**，对比度 ≥4.5:1
- 判据：眯眼时先看到「光在框上」而不是「字在发光」

**实现**：双主题 `[data-theme="cockpit"]`（默认）/ `calm`（保留旧版），顶栏左侧 22px 两态分段小件切换，不写 localStorage（保证默认恒为 cockpit）。
- cockpit 关键 token：`--bg-0 #04080E` / `--bg-1 #0A1520` / `--bg-2 #0E1C2A` / `--bg-3 #13293C`；`--pri #3B9EFF` / `--pri-2 #39D2E0`；`--ok #2FD9A8` / `--warn #FFAA3B` / `--danger #FF5C5C`；文字 `#E8F2FF` / `#AFC6DC` / `#7E96AE`
- 卡片：`clip-path` 右上+左下 16px 切角、1px 内描边 `.30`、辉光 `rgba(30,120,220,.10)`、顶部 1px 高光线、左上 8px 小方块
- 图表：柱体渐变 `#56B4FF→#1E5C99` + 顶部 1px `#A8D8FF` 亮边；环形用「段色 + 6px 辉光 + 端点 3px 圆点」而非整圈渐变（整圈渐变会让四段无法区分）
- 动效：入场 stagger 60ms、折线 `stroke-dashoffset` 600ms、数字 count-up 400ms、背景 18s 呼吸；全部走 transform/opacity/stroke，`prefers-reduced-motion` 关闭
- 两主题 21 栏高度完全一致（762/786/924），布局未动，只换皮肤

**已知取舍**：表格时间列 446px 栏宽下用 13px + `letter-spacing:-0.6px` 换空间（若退 12px 则违反字号地板，若 0 字距则 12 个单元格截断）。
