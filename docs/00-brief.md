# 「数智」综合驾驶舱 · 重设计 Brief

> 本文件是全团共享的唯一事实来源。所有成员必须以此为准，不得自行增删业务字段。

## 1. 项目背景

浙江省乔司监狱「数智」综合驾驶舱，面向监狱指挥中心大屏投放，共 7 个页面（1 个汇总首页 + 6 个业务板块）。
现存页面为典型「2015 式深蓝发光大屏」：靠堆叠发光与 3D 装饰建立层次，数据可读性差、栅格不统一、内容被裁切。

本次任务：**只重做视觉风格与布局，不改动任何业务数据结构（字段名、字段层级、字段含义全部保留）。**

## 2. 硬性约束

| 项 | 约束 |
|---|---|
| 数据结构 | **不可改动**。字段名、嵌套层级、字段顺序保持原样；仅可调整视觉呈现方式（排版、分组、排序展示、图表类型） |
| 目标屏幕 | 1920×1080 为设计基准；同时兼容 2560/3840 大屏与 1440/1280 宽度的桌面浏览器（流式栅格 + 断点，不出现内容裁切） |
| 视觉方向 | **炫酷科技风**：有科技感、未来感，可以使用 3D 装饰、动态图表、交互元素等。 |
| 交付物 | ① 视觉设计规范（色板/字体/栅格/组件/图表规范）② 7 个页面的高保真可交互 HTML 原型 |
| 语言 | 简体中文界面 |

## 4. 必须解决的问题（验收清单）

### 视觉（炫酷科技风 · 装饰级 3D）

> 定档 L1「装饰级」：光效、3D、动效只用于氛围与强调，不承载唯一信息；数据可读性优先级始终高于视觉冲击。

1. **光效分级，禁止无差别发光**：顶部栏、首页中区主视觉、预警/待办卡允许使用光效；数据卡片内部与外框一律用「1px 描边 + 底色阶差 + 精确内边距」建立层次。禁止大面积高饱和 `box-shadow`、斜切拼三角、无信息产出的粒子/扫描线堆砌。
2. 建立完整深色中性色阶（7 级灰蓝），保证**关闭全部光效后**仍能一眼分清「画布 / 区块 / 卡片 / 悬浮层」——该状态同时作为低配播控机的降级模式。
3. **色板分两层**：数据层降饱和（政务蓝主色 + 预警橙/危险红/正常青绿，语义色只表达状态）；光效层允许高饱和青蓝，仅用于装饰描边、流动路径、强调点。两层不得混用。
4. 表格正文最小 12px（1920 基准），行高 ≥ 1.6；**光效叠加后**正文对比度仍需 ≥ 4.5:1，发光元素不得压在数据文字下方。
5. **3D 与动效约束**：首页中区可保留 3D 地球/场景作为背景装饰层，但必须低透明度、不遮挡数据、可一键关闭；中区信息主体仍为「板块健康度矩阵 + 跨板块 Top 异常」。动效在入场后必须静止，循环动效仅限非数据区；须提供「降低动效」模式，低配设备自动降级。

### 布局
6. 统一栅格：12 列 + 24px gutter + 统一页边距，三栏比例固定，卡片底边对齐
7. 底部导航不得覆盖内容区，改为固定预留高度或收进顶部
8. 消除所有溢出裁切（表格、图例、柱图基线必须完整可见）
9. 顶部栏瘦身，天气/温度降为次要信息，让位给「数据更新时间 + 异常总数 + 全局筛选」
10. 板块标题统一为一种形态（编号 + 标题 + 计数 + 操作）

### 信息架构
11. 首页重构为真正的汇总页：全局态势 KPI → 板块健康度 → Top 异常聚合
12. 预警条目必须带优先级与排序依据（严重度 / 发生时间），不得平铺
13. 每个关键数字必须带口径（单位、统计区间、环比）
14. 消除同一模块在首页与业务页的重复呈现（首页只给摘要 + 下钻入口）
