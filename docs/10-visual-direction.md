## 0. v2 变更摘要（30 秒读懂差异）

| 维度 | v1.0（深沉政务风） | v2.0（炫酷科技风 · 装饰级） | 为什么变 |
|---|---|---|---|
| 总体策略 | 去光效、去 3D | **双层系统**：数据层守可读性，氛围层做科技感 | 视觉方向调整 |
| 发光 | 全站禁止 | **预算制**：分级授权、限量、可关闭 | 科技感必须靠光，但光会吃对比度 |
| 3D | 首页必须移除 | **允许作背景装饰层**，不得占信息位 | 定档 L1 装饰级 |
| 动效 | 仅 300ms 入场，禁止循环 | 入场 600–900ms，非数据区允许循环，可降级 | 科技感依赖动效节奏 |
| 色彩 | 全站降饱和、单主色 | **数据层降饱和 + 光效层高饱和青蓝** | 两层分离，互不污染 |
| 卡片 | 1px 描边 + 底阶差 | 1px 渐变描边 + 顶部高光 + 限量角标 | 科技感形态 |
| 图表库 | 手写 SVG | **ECharts 5 本地打包**（裁定 D6） | 动效/交互成本 |
| 可读性 | 12px 地板、4.5:1 | **不变**，且要求「光效叠加后」仍达标 | 底线不下调 |
| 布局 | 12 列 / 三栏 | **完全不变** | 与视觉方向无关 |

**一句话**：v2 不是在 v1 上加发光，而是把界面拆成“数据面”和“氛围面”两层——氛围面可以很炫，数据面仍按 v1 的标准做。

## 1. 设计立场（5 条，每条附带可判断的取舍标准）

### 立场 1｜双层系统：数据面守规矩，氛围面负责“炫”

任何像素必须先归属一层：

- **数据面**：文字、数字、表格、图表主体、轴、图例、口径。规则沿用 v1——降饱和、1px 描边、色阶分层、12px 地板、对比度 ≥ 4.5:1。
- **氛围面**：背景底光、卡片描边光、角标、中区 3D、流动路径、入场动效。允许高饱和青蓝、允许发光、允许动。

**取舍标准**：随手截一张图并转灰度，数据面必须仍然可读；氛围面转灰度后可以完全消失，不影响任何判断。

### 立场 2｜光效是预算，不是背景

发光只有两种合法用途：**指示焦点**（哪里要你看）和**表达状态**（哪里有问题）。没有第三用途。

**取舍标准**：指着屏幕上任何一处发光问“它想让我看什么”，答不出来就是违规。全屏发光面积超过 15% 视为“光墙”，直接回炉。

### 立场 3｜3D 只做背景，不占信息位

3D 的职责是建立空间感，不是承载数据。中区真正的信息主体是「板块健康度矩阵 + 跨板块 Top 异常」。

**取舍标准**：关掉 3D 后，中区信息量不得减少一条；如果减少，说明 3D 抢了信息的位。

### 立场 4｜动效服务于状态，不服务于循环

入场、数值变化、页面切换可以动；数据静止时画面必须静止。

**取舍标准**：连续观察 30 秒，除指定装饰区外，画面不应有任何持续运动。值班室 7×24 运行，循环动效 = 视觉噪音 + GPU 空转。

### 立场 5｜降级后仍然成立

所有光效、3D、动效必须能一键关闭，且关闭后是一个完整的、可交付的界面。

**取舍标准**：`data-fx="off"` 状态下截图，若出现“这里本来有个东西”的空洞感，则布局依赖了装饰层，不通过。

## 2. 色板（双层）

### 2.1 背景层级（沿用 v1，实测对比度可直接复用）

| Token | HEX | CIE L\* | ΔL\* | 用途 |
|---|---|---|---|---|
| `--bg-canvas` | `#0B1017` | 4.5 | — | 页面画布、顶栏、底导航 |
| `--bg-region` | `#101822` | 7.9 | +3.4 | 区块底、表头、输入框 |
| `--bg-card` | `#141E2A` | 10.9 | +2.9 | 业务卡片底（全站主用） |
| `--bg-elevated` | `#1C2836` | 15.7 | +4.8 | 下拉、Popover、Tooltip、模态、行 hover 峰值 |

**v2 新增 · 环境底光（每页仅 1 处，随页面固定）**

```css
.page {
  background:
    radial-gradient(1200px 620px at 50% -12%,
      rgba(59, 169, 255, 0.10) 0%,
      rgba(34, 211, 238, 0.04) 42%,
      transparent 72%),
    var(--bg-canvas);
}
```

- 位置固定在顶部中央，形状与尺寸**不得随页面变化**；
- 只有蓝色一个色相，透明度合计 ≤ 0.14；
- **禁止动画**（呼吸、缓慢位移都不允许）；
- 这是全站唯一允许的“大面积底色渐变”。

### 2.4 光效层（v2 新增，**只允许出现在非数据元素上**）

| Token | 值 | 用途 | 禁区 |
|---|---|---|---|
| `--glow-cyan` | `#22D3EE` | 角标、1px 高光线、流动路径、3D 边缘光 | 不得作为图表序列色、不得作为状态色 |
| `--glow-blue` | `#3BA9FF` | 环境底光、主数值微光、3D 主光源 | 同上 |
| `--glow-cyan-line` | `rgba(34,211,238,0.55)` | 1px 结构光线 | 不得用于 ≥2px 的线 |
| `--glow-cyan-soft` | `rgba(34,211,238,0.16)` | 角标底、路径光晕 | 不得作为卡片大面积底色 |
| `--glow-blue-soft` | `rgba(59,169,255,0.12)` | 环境底光外圈 | 同上 |

**硬规则**

1. 光效层**只有 2 个色相**（青 `#22D3EE`、蓝 `#3BA9FF`），不得引入紫、洋红、绿光，否则立刻滑向“RGB 电竞风”。
2. 光效色**不参与数据编码**：图表序列、状态徽标、环比涨跌一律使用 §2.3 / §2.5 的 token。
3. 光效色用于文字时，对比度仍需 ≥ 4.5:1，且仅限标题/强调，不得用于正文。
4. 光效色不得出现在表格内部（行线、单元格、表头底色）。

| 状态 | 文字色 | 卡片底对比度 | 底色形态 | 唯一允许位置 |
|---|---|---|---|---|
| 正常 / 达标 | `--ok-text` `#3FC1A7` | **7.5 : 1** | `rgba(63,193,167,0.12)` | 达标徽标、向好环比、正常状态点 |
| 预警 / 关注 | `--warn-text` `#DC9F46` | **7.3 : 1** | `rgba(220,159,70,0.12)` | 预警条目、阈值接近、待处理计数 |
| 危险 / 超限 | `--danger-text` `#E5746E` | **5.7 : 1** | `rgba(229,116,110,0.12)` | 严重预警、超时、超阈值、恶化环比 |

- 语义色只表达状态，不得用于标题、tab 激活、按钮、装饰线。

| 序 | HEX | 用途 |
|---|---|---|

| S2 | `#3FC1A7` | 第二序列 |
| S3 | `#DC9F46` | 第三序列 |
| S4 | `#8B7FD1` | 第四序列（低饱和紫） |
| S5 | `#7A93AC` | 第五序列（灰蓝） |

### 2.7 禁用清单（v2 版）

```
禁止 大面积彩色外晕      单元素 blur > 24px 或 alpha > 0.35

禁止 光墙               全屏彩色发光面积 > 15%
禁止 三色相以上渐变      任何渐变最多 2 个色相

禁止 无信息产出的全屏粒子 粒子雨、星点、雪花铺满画布
禁止 3D 承载唯一信息     关掉 3D 后必须仍可完整判读
禁止 backdrop-filter     卡片、顶栏、底导航一律禁用
禁止 彩虹仪表            仪表 / 环形出现 ≥3 色相分段
```

## 3. 光效系统（v2 核心章）

### 3.1 分级（L0–L3）

| 级别 | 名称 | 允许位置 | 单屏数量 | 典型元素 |
|---|---|---|---|---|
| **L0** | 无光 | 表格、图表主体、正文、数据卡内部 | 不限 | — |
| **L1** | 结构光 | 所有卡片、顶栏、底导航 | 不限（但须低对比） | 1px 渐变描边、顶部高光线、四角角标、环境底光 |
| **L2** | 强调光 | 预警卡、hover/focus、选中、主 KPI 数字 | **≤ 6 处** | 外晕、数字微光、焦点环 |
| **L3** | 主视觉光 | 首页中区 3D、顶栏光带 | **≤ 2 处 / 页** | 3D 场景、流光带 |

> L1 是“结构”，可以铺满；L2/L3 是“焦点”，多了就等于没有焦点。

### 3.2 光效白名单（8 种，超出即违规）

**L1-1 · 顶部高光线**（所有卡片）

```css
.card::before {
  content: "";
  position: absolute; inset: 0 0 auto 0;
  height: 1px;
  background: linear-gradient(90deg,
    transparent 0%,
    var(--glow-cyan-line) 28%,
    var(--glow-cyan-line) 72%,
    transparent 100%);
  opacity: .45;
  pointer-events: none;
}
```

**L1-2 · 1px 渐变描边**（卡片默认外框）

```css
.card {
  border: 1px solid transparent;
  border-radius: var(--r-sm);
  background:
    linear-gradient(var(--bg-card), var(--bg-card)) padding-box,
    linear-gradient(135deg,
      rgba(34, 211, 238, 0.38) 0%,
      rgba(47, 116, 192, 0.10) 38%,
      rgba(34, 211, 238, 0.18) 100%) border-box;
}
```

- 只允许 1px；渐变只允许青→蓝两个色相；
- 描边 alpha 峰值 ≤ 0.40，保证不盖过标题；
- **降级态**（`data-fx="off"`）回退为 `border: 1px solid var(--border-default)`。

**L1-3 · 四角角标**（仅关键卡：首页健康度格、KPI 卡，单屏 ≤ 2 张）

```css
.card--tech::after {
  content: "";
  position: absolute; inset: 8px;
  pointer-events: none;
  opacity: .55;
  background:
    linear-gradient(var(--glow-cyan), var(--glow-cyan)) left top / 12px 1px no-repeat,
    linear-gradient(var(--glow-cyan), var(--glow-cyan)) left top / 1px 12px no-repeat,
    linear-gradient(var(--glow-cyan), var(--glow-cyan)) right bottom / 12px 1px no-repeat,
    linear-gradient(var(--glow-cyan), var(--glow-cyan)) right bottom / 1px 12px no-repeat;
}
```

- 只做对角两角（左上 + 右下），四角全做 = 旧设计；
- 角标不得进入卡片内容 padding 区（`inset: 8px` 固定）。

**L1-4 · 环境底光**（每页 1 处，见 §2.1）

**L2-1 · 预警卡外晕**

```css
.card[data-tone="alert"] {
  box-shadow:
    0 0 0 1px rgba(220, 159, 70, 0.26),
    0 0 18px rgba(220, 159, 70, 0.14);
}
```

- 色值取该卡最高严重度；
- 只有“内容本身是告警集合”的卡片可用；
- 同排相邻卡片最多 1 张有外晕（防止连成光带）。

**L2-2 · 主数值微光**（仅 `--fs-display` 44px 数字）

```css
.kpi-display {
  text-shadow: 0 0 18px rgba(59, 169, 255, 0.26);
}
```

- 每屏 ≤ 2 个数字；
- 颜色只能取 `--glow-blue`；
- 12–32px 的数字**禁止**加 text-shadow（会糊）。

**L3-1 · 中区 3D**（见 §4.2）

**L3-2 · 顶栏光带**

```css
.topbar::after {
  content: ""; position: absolute; inset: auto 0 -1px 0; height: 1px;
  background: linear-gradient(90deg, transparent, rgba(34,211,238,.65) 22%, rgba(59,169,255,.65) 78%, transparent);
  opacity: .7;
}
```

### 3.3 光效预算（量化，验收直接数）

| 指标 | 上限 | 测量方法 |
|---|---|---|
| 彩色外晕元素数（L2） | ≤ 6 / 屏 | 截图后数 |
| 主视觉光（L3） | ≤ 2 / 页 | 截图后数 |
| 全屏彩色发光面积 | ≤ 15% | 截图 → 阈值提取发光像素 → 面积占比 |
| 单元素 blur | ≤ 24px | CSS 审查 |
| 单元素 alpha 峰值 | ≤ 0.35 | CSS 审查 |
| 单元素 spread | ≤ 8px | CSS 审查 |
| 同排相邻发光卡 | ≤ 1 张 | 截图后数 |
| 数据区（表格/图表主体）发光元素 | **0** | CSS 审查 + 截图 |

### 3.4 “光墙”自检

把页面截图缩到 320px 宽再看：

- 如果整体变成一片均匀发亮的蓝雾 → 光墙，不通过；
- 如果能一眼找出 3–5 个亮点（且这些点正好是关键数据）→ 通过。

### 3.5 LED 拼接现场修正

LED 屏有背光溢出（bloom），设计稿上的光效到现场会二次扩散。落地规则：

1. 现场调试时，所有光效 alpha × **0.6**；
2. 单元素 blur 从 24px 收到 **16px**；
3. 预留调试开关：`data-fx="led"` 时自动应用上述衰减；
4. **以现场实拍为准**，不以显示器截图验收。

## 4. 3D 与动效

### 4.1 三层结构（首页中区）

> **2026-11-08 实施修订**：中栏被健康度矩阵（286）+ Top 异常（460）满铺，762px 内没有可供 3D 常驻的空位。若把球放在卡片下方，被不透明卡面遮挡后有效亮度只剩 1–4%，肉眼不可见。故调整为「**概览卡内底纹**」：球画在卡面之上、文字之下。

```
┌─ z:0  背景装饰层：健康度矩阵卡内底纹（3D 线框球）  有效线亮度 ≤ 15%
├─ z:1  信息主体层：健康度矩阵 + Top 异常（文字在最上层）
└─ z:2  交互层：点击下钻、hover 提示
```

### 4.2 中区 3D 规格

| 参数 | 值 |
|---|---|
| 尺寸 | 健康度矩阵卡内部（1920 下 **916×286px**），不得越出卡片 |
| 球径 | `min(卡宽 × 0.22, 卡高 × 0.40)`，1920 下约 228px |
| 内容 | 线框球（经线 / 纬线 / 点云），**不得出现文字标签贴在 3D 上** |
| 可见度 | canvas `opacity 0.45`，线 alpha 0.30 → 有效线亮度 ≈ **13%**；以「看得见但不抢数据」为准 |
| 事件 | `pointer-events: none`，不抢点击 |
| 渲染 | 独立 `<canvas>`，Canvas2D 绘制（无 WebGL 依赖），**不得与图表共用容器** |
| 帧率 | 装饰 canvas ≤ **30fps**；页面 `visibilitychange` 隐藏时暂停 |
| DPR | `Math.min(devicePixelRatio, 2)` |
| 关闭 | 顶栏「特效」开关，或 `data-fx="off"` |
| 兜底 | Canvas 不可用时画一帧静态帧；仍不可用则不显示，不影响任何信息 |

### 4.3 动效 token

```css
--dur-enter: 720ms;                    /* 入场：卡片浮现、图表绘制、数字滚动 */
--dur-state: 160ms;                    /* 状态：hover、选中、展开 */
--dur-loop:  8s;                       /* 循环：仅装饰层 */
--ease-enter: cubic-bezier(.16, 1, .3, 1);
--ease-state: cubic-bezier(.4, 0, .2, 1);
--stagger: 40ms;                       /* 同屏卡片依次入场间隔 */
```

**规则**

| 场景 | 时长 | 缓动 | 备注 |
|---|---|---|---|
| 卡片入场 | 720ms | `--ease-enter` | 位移 ≤ 8px + 透明度，按 40ms 错峰 |
| 数字滚动 | 720ms | `easeOutExpo` | 只滚一次，结束后静止 |
| 图表绘制 | 720ms | `cubicOut` | ECharts `animationDuration: 720` |
| 数据实时更新 | 300ms | `easeOutCubic` | `animationDurationUpdate: 300` |
| hover / focus | 160ms | `--ease-state` | 只改描边、底色、位移 ≤ 2px |
| 装饰循环 | 8–12s | `linear` / `ease-in-out` | 仅中区 3D、顶栏光带 |
| 页面切换 | 420ms | `--ease-enter` | 淡入，不做 3D 翻转 |

**禁止**

- 动效改变布局尺寸（不得用 height/width 动画撑开容器）；
- 数据区循环动效；
- 超过 2 个元素同时入场且延迟差 < 20ms（会糊成一片）；
- 任何动效导致首屏可读数出现时间 > 1.2s。

### 4.4 降级策略（必须实现）

```html
<html data-fx="on">      <!-- on | led | off -->
<html data-motion="full"> <!-- full | reduced -->
```

| 模式 | 触发条件 | 行为 |
|---|---|---|
| `data-fx="off"` | 手动开关 / 低配设备 | 关闭 L2/L3 光效、3D、环境底光；保留 L1 结构光（或全部回退为实线描边） |
| `data-fx="led"` | 现场拼接屏 | 光效 alpha ×0.6、blur ×0.67 |
| `data-motion="reduced"` | `prefers-reduced-motion: reduce` 或手动 | 所有时长 → 0.01ms；3D 停帧；循环停止 |
| `data-motion="full"` | 默认 | 正常执行 |

**降级态落地 CSS（必须写，否则渐变描边会残留）**

```css
[data-fx="off"] .page { background: var(--bg-canvas); }
[data-fx="off"] .card {
  border: 1px solid var(--border-default);
  background: var(--bg-card);
  box-shadow: var(--shadow-1);
}
[data-fx="off"] .card::before,
[data-fx="off"] .card--tech::after,
[data-fx="off"] .topbar::after { display: none; }
/* 注意：不要写 .card::after —— 它会误删预警卡的语义竖条 */
[data-fx="off"] .kpi-display { text-shadow: none; }
```

**低配自动判定**：`devicePixelRatio × 屏幕面积` 超阈值、或 WebGL 初始化失败、或首帧渲染 > 100ms，自动切 `data-fx="off"` 并提示一次。

## 7. 核心组件视觉规范

### 7.1 业务卡片（科技感形态）

**结构**

```
外框     : 1px 渐变描边（青→蓝，alpha ≤ .40）        ← L1-2
顶部     : 1px 高光线（两端透明）                    ← L1-1
底色     : var(--bg-card) #141E2A
圆角     : 4px
padding  : 20px（紧凑 16 / 概览 24）
角标     : 仅关键卡，左上 + 右下，12px L 形          ← L1-3
外晕     : 仅预警卡                                   ← L2-1
```

**状态**

| 状态 | 变化 |
|---|---|
| 默认 | 渐变描边 + 顶部高光 |
| Hover（可点击） | 描边 alpha 提升至 .60；`background: #17222F`；位移 `translateY(-1px)`，160ms；**不加外晕** |
| 选中 | 描边换 `--blue-400`；底色 `rgba(82,144,218,0.06)`；左侧 2px 内嵌条 |
| 预警 | 左 3px 竖条 + 外晕（§3.2 L2-1） |
| loading | 内容区 40% 不透明 + 顶部 2px 进度条（`--blue-600`），不用骨架闪烁 |
| 空态 | 12px `--neutral-4` 居中「暂无数据」，高度 ≥ 120px |
| 错误 | 顶部 1px `--danger-text` + 12px 说明，不用红底 |
| 降级 | `data-fx="off"`：描边回退实线 `--border-default`，去高光、角标、外晕 |

**语义色条（裁定 D1，形态不变）**

```css
.warn-card::after {
  content: ""; position: absolute; left: 0; top: 0; bottom: 0;
  width: 3px; border-radius: 4px 0 0 4px;
  background: var(--sev-color);   /* 取该卡内最高严重度 */
}
```

- 只用于“内容本身是告警集合”的卡片；
- 常规数据卡不加任何色条；
- 竖条属于状态层，**禁止加发光**；
- `::before` 已被顶部高光线占用（§3.2 L1-1），故竖条使用 `::after`；因此**同一张卡不得同时挂 `.warn-card` 与 `.card--tech`**（角标也占 `::after`）。

### 7.2 板块标题（唯一形态）

```
[01] │ 模型数量分布                                13 项   ⋯
────────────────────────────────────────────────────────────
```

| 元素 | 规格 |
|---|---|
| 编号 | 12px / 600，`--neutral-4`，tabular-nums，固定宽 24px 右对齐 |
| 竖分隔 | 1px × 12px，`--border-strong`，左右各 10px |
| 标题 | 18px / 600，`--neutral-1`，letter-spacing +0.3px，单行 ellipsis |
| 计数 | 12px / 400，`--neutral-3`，格式 `13 项` / `273 人` / `2 例`，距标题 8px |
| 操作 | 默认 `⋯` 16px `--neutral-4`；有下钻改 `详情 ›` 12px `--blue-400` |
| 下分割线 | 1px `--border-divider`，`padding-bottom: 12px` |
| 整行高 | 44px |

**禁止**：`›` `❬` `▸` `「」` 装饰符；渐变短线；多字号混用；中文数字编号。

### 7.3 KPI 数字块

**一张卡内 4 格等分，格间 1px 竖线**，不拆成 4 个小盒子。

| 元素 | 规格 |

| 环比 | 12px / 500，箭头 8px + 数值；颜色由好坏决定：向好 `#3FC1A7`、恶化 `#E5746E`、中性 `#77A9E1` |
| 口径 | 12px / 400 `--neutral-4`，距数值 6px |
| 格高 | 104px（首页 display 版 132px） |

## 10. 与下游对齐的四条硬约定

1. **前端**：§2–§7 的所有数值直接复制为 CSS 自定义属性，落在 `:root` 与 `[data-fx]` / `[data-motion]` / `[data-reading-distance]` / `[data-density]` 四个选择器下。禁止组件内裸色值、裸字号、裸间距。落地顺序：token → 布局骨架（含 56px 预留）→ 光效层 → 卡片/标题 → 表格 → 图表 → 3D。

4. **不变式**：本文件未新增、未删除、未重命名任何业务字段。字段清单以 `00-brief.md` §3 为唯一准。
