# 设计决策记录（主理人裁定）

> 本文件解决 `10-visual-direction.md` §8-2 列的 3 个开放项。**已定，不再讨论**，Phase 2 / Phase 3 直接执行。

## D1 · 卡片语义色条形态 → 采纳「左侧 3px 竖条，仅预警/待办卡」

- 采纳视觉架构师判断：**取消顶部 2px 横条**。
- 理由补充：8 张卡并排时顶部横条会连成一条通栏横线，与原设计的顶部发光线同构，用户第一眼会判定「还是那个风格」，改造感归零。
- 执行细则：
  - 预警/待办类卡片（内容本身是告警集合）→ 左侧 3px 竖条，色值取该卡内**最高严重度**。
  - 常规数据卡（图表 / KPI / 表格）→ **不加任何色条**。
  - 竖条不圆角，与卡片 4px 圆角脱开。

## D2 · 导航形态 → **固定底部 56px**（不采用收进顶部）

- 理由：
  1. 7 个一级板块在大屏上是「平级并列」，底部横排等分是最快的一次点击路径，符合原用户肌肉记忆，学习成本为 0。
  2. 收进顶部会与顶部栏右侧的「更新时间 / 异常总数 / 全局筛选」争同一横向通道；1920 下 7 个 tab 各约 200px，还会挤压页面标题。
  3. 全局筛选属于「工具」，导航属于「位置」，两者分置上下最不易误点。
- 执行细则：`position: fixed; bottom: 0; height: 56px`，内容区**必须** `padding-bottom: 56px`（写进布局骨架）。全站**不得**出现第二组同款导航。

## D3 · 首页中栏承载 → 「七大板块运行健康度」矩阵 + 「跨板块 Top 异常」

原 3D 地球（916×420px）替换为上下两块，均由真实字段驱动：

1. **上半 · 板块健康度矩阵**（约 916×230px）
   - 7 个板块一行一格，格内三行信息：板块名 / 异常数（大数字 + 单位）/ 健康度状态（正常·关注·预警，用语义色 + 文字双编码）
   - 数据来源：各业务页 KPI 与预警计数的汇总（`00-brief.md` §3 已有字段，不新增）
   - 每格可点击 → 下钻到对应业务页
2. **下半 · 跨板块 Top 异常**（约 916×170px）
   - 跨 6 个板块聚合的严重预警，按严重度降序取 Top 5，每行：板块来源 + 事由 + 数值 + 时间
   - 对应 Brief §4-11 / §4-12：必须显式标注排序依据，不得平铺

- 收益：首页第一次有了「汇总 → 定位 → 下钻」的完整动线，而不是把二级内容平铺上来。

## D4 · 观看距离定档 → 默认 `mid`（1.5–3m 指挥席）

- 根节点默认 `data-reading-distance="mid"`。
- 顶部栏提供 `近 / 中 / 远` 三档切换（12px 文字 tab，非胶囊），仅切换字号 token，**不使用 `transform: scale()`**。
- `far` 档：display ×1.25、h1 ×1.20、h2 ×1.10、正文下限 14px、禁止 12px 承载数据、表格切宽松密度。

## D5 · 首页的「重复模块」处理

- `00-brief.md` §4-14：首页的「罪犯劳动报酬发放」与劳动改造页同名模块重复。
- 裁定：**首页保留该模块但只显示 Top 3 + 「共 5 项 · 详情 ›」下钻**，完整 5 项在劳动改造页呈现。字段不删不改，仅调整展示条数。

## D6 · 图表库策略

- 原型阶段**不引外部图表库**（ECharts/CDN 会增加离线打不开的风险）。
- 统一用**手写 SVG** 实现 4 类图表（折线 / 柱状 / 环形 / 仪表），参数严格按 `10-visual-direction.md` §5.6。
- 理由：7 个页面只有 4 类图表、约 18 个实例，手写 SVG 可控性更高、零依赖、打印/截图保真，且天然满足「无循环动画」的验收要求。
