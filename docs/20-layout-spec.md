## 0. 阅读指引与三条使用铁律

本规范的所有高度都是**算出来的**，不是"看起来差不多"。每个页面第 2 章各节末尾都给出「垂直高度闭合算式」，前端照抄即可闭合到 924px。

| 铁律 | 说明 | 违反后果 |
|---|---|---|
| **R1 高度闭合** | 每页 `左栏 / 中栏 / 右栏` 三列各自的卡片高度之和 + 卡间距 = 924px（含顶部 KPI 带的页面为 786px，见各页算式）。**不允许**出现"自适应""约""适当" | 三列底边不齐，Brief §4-6 不通过 |
| **R2 宽度闭合** | 每张表格 `table-layout:fixed`，列宽百分比之和 **= 100.00%**，末列右 padding 16px。**不允许**横向滚动 | 末列被裁，Brief §4-8 不通过 |
| **R3 不缩字号** | 12px 是地板。字段排不下时只能「减少同屏行数 + 表体内部滚动」或「合并同类列展示」 | 3m 外不可读，Brief §4-4 不通过 |

### 0.1 与视觉规范的数值调和（3 处，均为算术澄清，不改任何 token）

`10-visual-direction.md` 有 3 处组件高度与其自身内部元素之和不等。本规范统一按「元素实际高度之和」取值，并在下方给出推导，**不改色值、字号、间距档位**。若主理人要求严格回退到视觉文档原值，请见 §8.3 的三条影响说明。

| # | 视觉文档原值 | 本规范取值 | 推导 |
|---|---|---|---|
| N1 | 板块标题「整行高 44px（含分割线）」 | **44px**（保持原值） | 26px 文本行 + 12px `padding-bottom` + 1px 边框 = 39px；视觉文档的 44px 多出 5px，视为标题文字行盒的光学余量，本规范直接占用 44px 整块，**不再额外加 padding-top** |
| N2 | KPI 数字块「格高 104px」 | **122px** | 104px 未含口径副标行：指标名 20 + 4 + 数值 38 + 6 + **口径 18** + padding 20/16 = 122。Brief §4-13 强制每个关键数字带口径，因此 104 + 18 = 122 |
| N3 | 首页 44px KPI 版「格高 132px」 | **146px** | 132px 同样未含口径行：指标名 22 + 4 + 数值 48 + 6 + **口径 18** + padding 24/24 = 146 |

### 0.2 卡片高度通用公式（全 7 页复用）

```
标准卡（图表 / 列表，padding 20，标题下间距 12）
  卡高 = 20 + 44 + 12 + 内容高 + 20 = 内容高 + 96

表格卡（padding 20 20 12，标题下间距 12）
  卡高 = 20 + 44 + 12 + 内容高 + 12 = 内容高 + 88

概览卡（首页，padding 24，标题下间距 16）
  卡高 = 24 + 44 + 16 + 内容高 + 24 = 内容高 + 108

表体内容高 = 表头 36 + n × 行高 + (n − 1) × 1 + 分页(12 + 32 = 44)
预警列表内容高 = Σ 条目高 + (n − 1) × 1（单行 56 / 含副标双行 72）
```

## 第 1 章 · 全局骨架

### 1.1 1920×1080 三段高度账

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部栏                                                  64px │  ← position: sticky; top:0
├──────────────────────────────────────────────────────────────┤
│  内容区顶部内边距                                       20px │
│  ┌────────────────────────────────────────────────────────┐  │
│  │ 内容宽 1856px（= 1920 − 32×2）                 高 924px │  │
│  └────────────────────────────────────────────────────────┘  │
│  内容区底部内边距                                       16px │
├──────────────────────────────────────────────────────────────┤
│ 底部导航（fixed，内容区已预留）                          56px │
└──────────────────────────────────────────────────────────────┘
合计 = 64 + 20 + 924 + 16 + 56 = 1080 ✓
```

计算过程（可直接抄）：

```
1080 − 64（顶栏） − 56（底部导航预留） − 20（内容区上内边距） − 16（内容区下内边距） = 924px
```

- 底部导航 `position: fixed; bottom: 0; height: 56px`（裁定 D2），内容容器 `padding-bottom: 56px` 由上式已扣除，因此**内容区任何元素不得再与导航发生视觉重叠**。
- 内容区左右 `padding: 0 32px`；内容容器 `display:grid; grid-template-rows: 924px;` 不做 `min-height:100vh` 撑高，避免出现 924 之外的余量。
- 有顶部 KPI 带的页面（P0 / P1）在 924 内部再切一刀：`KPI带 + 16 + 三栏 = 924`，见 §1.4。

### 1.2 12 列栅格与三栏

```
内容宽 = 1920 − 32×2 = 1856
列宽   = (1856 − 11×24) / 12 = 132.67px
span(3) = 3×132.67 + 2×24 = 446px   ← 左/右栏
span(6) = 6×132.67 + 5×24 = 916px   ← 中栏
校验   446 + 24 + 916 + 24 + 446 = 1856 ✓
```

| 区域 | span | 宽 | 说明 |
|---|---|---|---|
| 左栏 | 3 | **446px** | 分布类 / 明细表 / 分值卡 |
| 中栏 | 6 | **916px** | 汇总矩阵 / 宽表 / 主图 |
| 右栏 | 3 | **446px** | 预警列表 / 状态卡 / 环形 |

列与列之间是 **gutter 24px**（不是卡片 margin）；同一列内卡片间距 **16px**。

### 1.3 三栏垂直分割规则（核心）

**规则**：每一页的三栏各自是一个 `display:flex; flex-direction:column; gap:16px; height:924px`（含 KPI 带页为 786px）的栈。栈内卡片高度**显式给定**，不使用 `flex:1` 自适应分配（除下文明确标注的"弹性卡"）。

```
列高 = Σ 卡高 + 16 × (n − 1)
每页每列必须满足：|列高 − 924| ≤ 1px（含 KPI 带页为 |列高 − 786| ≤ 1px）
```

**弹性卡例外**（仅 3 处，允许 `flex:1 1 auto`）：P3 中栏「临释罪犯重大违规违纪」（记录不足，需吃掉剩余高度做字段详情区）、P5 中栏「罪犯猝死风险评估」、P6 右栏「队伍风险追踪器」。其余卡片一律固定高度，保证跨页一致。

**卡片内部防溢出三件套**（Brief §4-8）：

```
.card            { display:flex; flex-direction:column; }
.card__body      { flex:1 1 auto; min-height:0; }   /* min-height:0 是关键 */
.table__viewport { overflow-y:auto; overflow-x:hidden; }
.chart__plot     { overflow:visible; }               /* 柱图基线不得被裁 */
```

> `min-height:0` 缺失 → Flex 子项不会收缩 → 图表/表体溢出卡片下边界 → 三栏高度集体不闭合。这是本项目第一大坑，见 §8.3。

### 1.7 纵向滚动的三条硬约束（1920 以下）

1. **只有页面滚动，卡内不滚整页**：D/E/F 档允许整页纵向滚动；C 档（≥1920）**禁止页面滚动**，只有表体、列表内部滚动。
2. **滚动时顶栏与底栏不动**：顶栏 `position: sticky; top:0`，底栏 `fixed`，两者之间才是滚动容器。
3. **sticky 表头与 sticky 顶栏不得打架**：表头 `top:0` 只在表体滚动容器内生效（`position:sticky` 相对最近的滚动容器），因此表体容器必须是独立 `overflow-y:auto` 元素，**不能**用整页滚动承载表体 sticky。

## 第 2 章 · 逐页布局

> 每页给出 4 件东西：① ASCII 线框图（宽度按 1856 标注）② 区块清单表（模块名严格取自 `00-brief.md` §3 原名）③ 垂直高度闭合算式 ④ 该页解决的 Brief 验收问题编号。
> 线框图中的 `▏` 表示 1px 分割线，`▌` 表示预警卡左侧 3px 语义竖条（裁定 D1）。

### 2.0 唯一高度公式（前端请当成法律条文）

**全站只有一条卡高公式**，任何卡片、任何页面都不允许出现第二种算法：

```
标准卡   卡高 = 内容高 + 96     （padding 20 + 标题块 44 + 标题下间距 12 + padding 20）
表格卡   卡高 = 内容高 + 88     （padding 20 + 44 + 12 + padding 12）
概览卡   卡高 = 内容高 + 108    （padding 24 + 44 + 16 + padding 24）
```

**三条配套约束（违反就算返工，不接受"看起来差不多"）**：

1. **卡高必须写 `height`，不写 `min-height`**；弹性卡（§1.3 列出的 3 处）例外，且只能出现在单卡满栏的位置。
2. **任何一处卡高改动，必须回本文档重算该列全部卡片**，保证 `Σ卡高 + 16×(n−1) = 924`（或 786 / 762）。改完把算式写回对应小节的「垂直高度闭合算式」。
3. **禁止"差 4px 手动补一下"**。这是前端拿到布局文档后最容易做的错事：给某张卡 `min-height + padding-top: 4px` 凑数，结果三栏底边差 4px、下一排卡片错位 4px，且无法从代码看出原因。差多少像素，就回文档改哪个内容段，而不是补白。

> 判据：`Σ卡高 + gap` 与目标值偏差必须 = 0 或 1（1px 为亚像素舍入余量）。偏差 ≥ 2px 一律回文档。

#### 2.6.3 图例「超出容器改两列」的具体阈值（Brief §4-8）

图例容器宽 = 卡内宽 − 环形区 − 间距：

默认：level 降序 → 发生时间降序 → 事由名字典序（保证稳定，不因同值抖动）
切换：点「时间」→ 时间降序 → level 降序（严重度徽标不消失，语义不丢）
切换控件：标题操作面 [严重度 | 时间] 两个 12px 文字 tab，激活态 = #DCE5EE + 2px 下划线
位置固定：L1 恒在列表顶部（切换为"时间"后若 L1 不在顶部，在列表头保留一条 24px 提示「严重项 3 条已折叠在顶部」并提供跳转）
```

**首页健康度格状态判定**（与上表同源，不另立标准）：

```
板块状态 = 该板块内出现 L1 → 预警（红）
         = 无 L1 且出现 L2 → 关注（橙）
         = 只有 L3 / L4   → 正常（青绿）
```

**禁止**：只用颜色区分级别；同一列表里混排不同级别却不给徽标；用 icon 代替文字徽标。

### 3.3 数字口径规则（Brief §4-13 强制）

**格式模板**

| 类型 | 模板 | 示例 | 单位位置 | 副标（12px，`--neutral-4`→实际用 `#8494A6`） |
|---|---|---|---|---|
| 绝对量 | `{数值} {单位}` | `1,792 人` | 数值右 4px，基线对齐 | `{统计类型} · {时点/区间}` |
| 均值型 | `{数值(保留源小数)} {单位}` | `220.49 人` | 同上 | `月均 · 统计区间 10-01~10-31` |
| 比率 | `{数值}%` | `56.5%` | `%` 紧贴无空格 | `{时点} · 口径：{n} 项加权` |
| 计数（例/项/件） | `{数值} {单位}` | `9 例` | 同上 | `{统计类型} · {区间}` |
| 分值 | `{数值}`（无单位） | `1.88` | 无 | `分值 · 区间 10-07~11-06` |
| 缺失 | `—` | `—` | 无 | `数据未接入`（必须同时出现，不允许只有破折号） |

**副标三段式（最多 3 段，用 ` · ` 分隔）**：
1. 统计类型：`累计` / `当前时点` / `月均` / `当日` / `近 30 日`
2. 时点或区间：`截至 11-06 17:11` / `统计区间 11-01 ~ 11-06`
3. 环比（可选）：`环比 +4.8%`

**规则**：
- 千分位用半角逗号（`1,792`），禁止 `1792` 或 `1 792`。
- 百分比保留与数据源一致的小数位，**不自行四舍五入**（`220.49` 保持 2 位；`56.5%` 保持 1 位）。
- 环比箭头 `↑ ↓ →`，颜色由**好坏**决定（向好青绿 / 恶化红 / 中性蓝），不由涨跌决定。
- 0 是有效值，显示 `0 例` 且配 `正常` 徽标；**不得**用 `—` 代替 0（`—` 只用于未接入）。
- 一个数字只有一个单位，单位不重复出现在标题、副标和数值里。

Tab ×1 → 顶栏「全局筛选」→ Tab → 全屏按钮 → Tab → 首页 KPI 卡（不可交互，跳过）
→ Tab 落在健康度格 1（监管改造）→ ←→ 在 6 格间移动 → Enter 进入 P1
→ 焦点落到 P1 页面标题（tabindex="-1"，可读不可 Tab）→ Tab 继续进入 P1 首个可交互元素

路径 2 · 在预警列表里切换排序
Tab 到「[严重度 | 时间]」分组 → ←→ 切 tab → Tab 进入第 1 条预警 → ↑↓ 移动 → Enter 下钻
Shift + Tab 反向回退，焦点顺序与视觉顺序一致（左→右、上→下）

路径 3 · 表格排序与翻页
Tab 到表头可排序列 → Enter 排序（三态循环）→ Tab 到表体（容器 tabindex=0）→ ↑↓ 选行 → Enter 选中

```

2. 每个可交互元素都有 `:focus-visible` 轮廓（≥2px，`#77A9E1`，6.8:1）。
3. 跳转后焦点必须被管理：下钻/切页后焦点移到新页 `h1`（`tabindex="-1"`），读屏播报页面名；返回后焦点回到触发元素。

### 6.1 五种状态的呈现（逐页具体化，不允许只写"显示空态"）

| 状态 | 触发 | 呈现（精确到像素） | 逐页差异 |
|---|---|---|---|
| **空态** | 数据源返回 0 条（非 0 值） | 卡片内容区居中：12px `#8494A6` 文字；**高度不低于 120px**；保留标题与计数位（计数显示 `0 项`） | P1/P3 表格：单行 40px 居中 `暂无数据`，**保留表头**；P2 报酬卡：5 项位置保留但显示「暂无未发记录」；P5 条形图：保留 8 条分监区坐标轴 + 居中 `暂无数据` |
| **加载态** | 首屏或全局筛选变更后 ≤ 300ms 内未返回 | 内容区整体 40% 不透明 + 卡片顶部 2px `#5290DA` 进度条（宽 0→100%，600ms ease-out）；**不用骨架闪烁** | P0 健康度矩阵：6 格保持占位灰块（每格 12px 四级堆积条整体变 `#232F3D`）；P4 仪表：弧回落到 0°，不显示指针 |
| **错误态** | 接口失败 | 卡片顶部 1px `#E5746E` 横线 + 下方 12px 说明「数据获取失败 · 3s 后自动重试」+ 一个 `重试` 文字按钮；**不用红底** | P1 表格：表头保留，表体显示 1 行错误行；P0 KPI 带：单格显示 `—` + `获取失败`，其余格正常（局部失败不拖全页） |

### 8.2 最容易踩的 3 个坑（按发生概率排序）

**坑 1 · flex 收缩导致图表/表体溢出卡片**
- 症状：卡片高度看着对，但柱图基线被切、表体压住分页。
- 根因：`flex:1` 子项默认 `min-height:auto`，不会收缩到内容高度以下。
- 解法：`.card__body { flex:1 1 auto; min-height:0 }`；图表容器 `overflow:visible` 但**高度显式**（如 P1 绘图区 140px）；表体 `overflow-y:auto` 且**只有它能滚**。
- 自检：`document.querySelectorAll('.card__body').forEach(e => e.scrollHeight > e.clientHeight + 1 && console.warn(e))` → 应为空。

**坑 2 · 表格列宽百分比不闭合**
- 症状：末列被切一半，或出现 1px 横向滚动条。
- 根因：百分比之和写成 99% / 101%；或 `border-collapse` 下 1px 边框计入宽度；或用 `padding` 而非 `box-sizing:border-box`。
- 解法：7 张表的百分比按 §2.2–§2.4 抄死；`table { width:100%; table-layout:fixed; border-collapse:collapse; }`，单元格 `box-sizing:border-box`；`overflow-x:hidden` 兜底但不作为方案。
- 自检：`[...table.querySelectorAll('col')].reduce((s,c)=>s+parseFloat(c.style.width),0) === 100`。

**坑 3 · 三栏高度不闭合**
- 症状：三栏底边差 5–20px，最后一排卡片悬空或溢出。
- 根因：把 §1.5 的卡高当成"建议值"改了；或标题块按 39px 而非 44px；或用 `gap` 又加了 `margin`。
- 解法：卡高**显式写死**（`height:494px` 而不是 `min-height`）；标题块 44px（不是 39）；间距只用 `gap:16px`，`margin` 归零；改任何卡高必须重算同列其他卡高，保持列和 = 924。
- 自检：`[...columns].forEach(c => console.log(c.reduce((s,card)=>s+card.offsetHeight,0) + 16*(n-1)))` → 全部 924（或 786）。

## 第 9 章 · 空态与低数据版面重分配（v1.2 增补）

> 起因：原型落地后逐页截图发现**版面级**问题——9 处 noData 卡与若干低数据卡在 1920×1080 上形成大量"无效空白"，P1/P4/P6 看起来像没做完。这不是前端实现失误，是规范只规定了"高度闭合"，没规定"高度里必须装东西"。
> 本章三条原则（E1/E2/E3）**优先级高于 §2 各页的原始卡高**，冲突时以本章为准；§2 各页的闭合算式已按本章同步修订。

### 9.1 三条新原则

#### E1 · 空卡预算

单张 noData 卡（数据源未接入）高度**上限 140px**，且**禁止出现"一张卡只有一行字"**。

```
占位卡 140 = 72（标题区）+ 68（说明区）
            ├ 16 padding-top + 44 标题块 + 12 间距 = 72
            └ 48 说明区（两行 12px/18 + 12 呼吸）+ 20 padding-bottom = 68
```
- 说明区两行固定文案：第 1 行「数据源未接入，接入后自动展示」；第 2 行「不影响本页其余口径与合计」（12px `#8494A6`）。
- **判据**：全站 `noData` 卡高 ≤ 140px；每张卡内文字行数 ≥ 2；`> 140px` 的 noData 卡出现次数 = 0。
- **不允许**用「放大占位卡」凑高度：卡矮了就从**别处**找内容，不许给空卡加白。

#### E2 · 合并阈值

**同栏 noData 卡 ≥ 3 张时，合并为一张「待接入模块 (N)」聚合卡**；2 张时同样合并（见 9.3 例外说明）。

```
聚合卡(N) = 16 + 44 + 12 + [N × 52 + (N−1) × 1 + 1] + 20
  单模块行 52 = 模块名 14px/22 + 6 + 状态行 12px/18 + 6（行间 1px 分割，末行下 1px 收口）
  N=3 → 251px     N=2 → 198px
```
- 每行左侧模块名（14px `#DCE5EE`，单行 ellipsis），右侧 `[未接入]` 徽标（20px 高，`#5F6E80` 文字 + `rgba(95,110,128,0.12)` 底），行下 12px 状态行写「原计划位置：{栏位} · 见 §2.x」。
- **禁止**写成「3 个模块」或「部分模块未接入」了事——**必须逐个列出模块原名**。判据：聚合卡内出现的模块名数量 === `N`。

#### E3 · 释放高度必须转化

释放出的每一像素必须转成**表格行数**、**行高**或**图表尺寸**，**不许留白**。留白等于没释放。

| 转化出口 | 允许做法 | 不允许做法 |
|---|---|---|
| 表格 | 提高同屏行数；行高由 32 → 40 → 50（50 = 宽松密度，visual §5.5） | 卡内底部留空；挪出 `padding-bottom` 凑数 |
| 横向条形 | 提高条高（如 P5 8 条由 92 → 96/条）；提高条间距 | 只把容器拉高、条不放大 |
| 环形 / 仪表 | 提高环径（120 → 160 → 200 → 240，配套环宽 12 → 16 → 20 → 24） | 环不变、四周留白 |
| 柱图 | 提高绘图区高度、柱宽、组间距 | 柱不变、画布变大 |
| 列表 | 提高条目高度（56 → 72 → 144），并按 §2.4.4 边界约束 | 只用 `justify-content:space-between` 拉开 |

- **判据（可量）**：每张卡 `内容占位高度 / (卡高 − 96 或 −88 或 −108)` ≥ **0.92**；即卡内底部空白 ≤ 8%。低于 0.92 的卡必须回本章重分配。
- 自检脚本思路：`card.__body.scrollHeight / card.__body.clientHeight ≥ 0.92`（排除表体滚动容器）。

### 9.4 对主理人给定方向的 2 处调整（附算术理由）

**调整 1 · P1 的结构不是我图中那样，按可用宽度重排**
你给的 P1 是「左栏 04+05+07 = 1046px」。实际三栏各 786px，1046 > 786 说明那三张卡横跨了两栏。新方案把 3 张空卡合并成 251px 聚合卡放**左栏**（与项危表同栏），中栏给涉黑表独占 786（13 条 × 50px），右栏给预警独占 786（7 条 × 72px 双行）。这样两张表都能一屏直出、取消分页，且三栏各自精确闭合。

**调整 2 · P5 的「3 张分值卡合并为 240」** **不执行**，算术上会导致空栏：
- P5 只有 **2 个模块**（医疗隐患、猝死评估）。v1.1 之所以把猝死评估拆成「环形卡 + 3 分值卡」，就是因为 2 个模块填不满 3 栏。
- 若把 3 分值压成 1 张 240 的卡，右栏剩 `924 − 240 = 684px` 无内容可放——**而三栏不能互相转移高度**（每栏独立闭合），中栏环形已经在 924，吸不走这 684。
- 因此对 P5 采用**替代方案**：保留 3 张分值卡（300/300/292），但按 E3 把每张卡从"1 个数字"扩成 6 行结构（徽标 + 分值 48px + 指标名 + 口径 + 含义说明 2 行 + 环比），并把中栏环径 120 → 240 用掉纵向余量。**闭合不变，无空白**。
- 若你坚持合并，唯一闭合解是「右栏 240 分值卡 + 668 的派生卡（医疗隐患按人数分档速览）」，但那会让同一模块在两栏各出现一次，我不建议。

**通用提醒（会影响后续所有页面）**：三栏栅格中**高度不可跨栏转移**。某栏释放的高度只能被**同栏**的卡片吸收（放大图表/行高），或把别的卡**移入**该栏后重新分配。因此"把右栏余量给中栏柱图"这类方向，落地方式必须是「柱图搬到中栏并独占」，而不是"中栏变高"。

### 9.5 分页策略（替换 §4.3「一律 10 条/页」）

```
记录数 n ≤ 14  → 取消分页控件，全量显示，标题操作面标注「共 n 条 · 已全部显示」
记录数 n > 14  → 启用分页，10 条/页，分页条 44px（12 间距 + 32 高）
```
- 阈值 14 的来源：786 / 924 栏高下，40px 行高最多容纳 ~14 行而不挤压表头与操作面；≤14 条时全量显示更利于"一屏读全"。
- **取消分页时表卡高度 = 88 + 表头 36 + n×行高 + (n−1) + 底注条（可选）**；`共 n 条 · 已全部显示` 放标题操作面，**不占表体高度**。
- 阈值切换必须整页一致：同一页两张表（如 P1 项危 12 / 涉黑 13）都 ≤ 14 → 两表都不分页。
